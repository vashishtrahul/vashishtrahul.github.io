# Bias Variance Tradeoff Intuition & Theory

## The Setup
Consider a dataset of points <br>


\begin{equation}\{(x_1, y_1), \ldots, (x_n, y_n)\}, \quad y_i \in \mathbb{R}\end{equation}
sampled according to the joint distribution $$ \mathbb{P} (X, Y) = \mathbb{P} (Y \mid X) \mathbb{P}(X).$$

**Intuition**: We have training data where each input $$x_i$$ has a corresponding output $$y_i$$. This data comes from some unknown "true" relationship between inputs and outputs.

---

## 1. Expected Label (The "True" Answer) 

**Definition:** For given input $$x \in \mathbb{R}^{d}$$, what should the "perfect" output be on average?

$$\bar{y}(x) = \mathbb{E}_{y \mid x}[Y] = \int\limits_{y} y \, P(y \mid  x) \, \partial y$$


**Intuition:**

- Imagine you have access to true data distribution and thus have all possible $$(x,y)$$ pairs
- Due to stochasticity, for a specific input $$x$$, we get different $$y$$ values
- $$ \bar{y}(x) $$ is the average of all those $$y$$ values for given $$x$$
- This represents **best possible prediction** for input $$x$$


**Example**: If you're predicting house prices, $$\bar{y}(\text{house})$$ is the average price of all houses exactly like this one in the true population.


## 2. Expected Test Error (How Wrong Are We?)

**Definition**: For given trained model $$h_{\mathcal{D}}(x)$$, how much error do we incur on new, unseen data on average? 

$$\mathbb{E}_{(x,y) \sim \mathbb{P}} \bigg[ (h_{\mathcal{D}}(x) - y )^2\bigg] = \int\limits_x \int\limits_y   (h_{\mathcal{D}}(x) - y )^2 P(x,y)\partial y \partial x $$

**Intuition:**
- Take your trained model $$h\_{\mathcal{D}}$$ (trained on dataset $$\mathcal{D} \sim \mathbb{P}^{n} $$)
- Test it on a random new point $$(x,y)$$ from the same distribution
- Measure the squared difference between your prediction and the true label
- Average this error over ALL possible test points
- This tells you how well your model generalizes

**Key insight**: This error depends on your specific training set $$\mathcal{D}$$. Different training sets will give different models with different test errors.


## 3. Expected Classifier (The "Average" Model)

**Definition:**  Given machine learning algorithm $$\mathcal{A}$$, trained on different datasets of same size,what would the "average" model look like?


$$\bar{h}(x) = \mathbb{E}_{\mathcal{D} \sim \mathbb{P}^{n} } \left[ h_{\mathcal{D}}(x) \right] = \int h_{\mathcal{D}}(x) P(\mathcal{D}) \, d\mathcal{D}$$

**Intuition**:
- Imagine you could sample many different training sets of size $$n$$
- Train your algorithm $$\mathcal{A}$$ on each training set, getting models $$h\_{\mathcal{D}\_1}, h\_{\mathcal{D}\_2}, \ldots$$
- For any input $$x$$, average the predictions of all these models
- $$\bar{h}(x)$$ is this averaged prediction
- This represents what your algorithm "tends to predict" for input $$x$$


**Example**: If you train linear regression on 1000 different datasets, $$\bar{h}(x)$$ is the average of all those 1000 linear models' predictions at point $$x$$.



## Key Intuitions

1. **$$\bar{y}(x)$$** = What nature/reality says the answer should be
2. **$$h\_{\mathcal{D}}(x)$$** = What your specific trained model predicts  
3. **$$\bar{h}(x)$$** = What your algorithm typically predicts across different training sets

## 4. Expected Test Error given an algorithm $$\mathcal{A}$$

**Definition:** For a given algorithm what is error on new point $$x$$ on average? 

$$\mathbb{E}_{(x,y) \sim \mathbb{P}, ~ \mathcal{D} \sim \mathbb{P}^{n}  } \bigg[ (h_{\mathcal{D}}(x)- y )^2 \bigg]  = \int\limits_{\mathcal{D}} \int\limits_{x} \int\limits_{y} (h_{\mathcal{D}}(x)- y )^2 P(x,y) P(\mathcal{D}) \partial y \partial x \partial \mathcal{D} $$

 
Here, $$\mathcal{D}$$ represents our training set and the $$(x,y)$$ pairs are the test points. We are going to decompose the expected test error given an algorithm $$\mathcal{A}$$. Because it evaluates the quality of a machine learning algorithm $$\mathcal{A}$$ with respect to a data distribution $$\mathbb{P}(X,Y)$$. Below we will show that this expression decomposes into three meaningful terms.

## 5.  Decomposition of Expected Test Error 


$$\begin{align}\mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ (h_{\mathcal{D}}(x)- y )^2 \bigg] &= \mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x) + \bar{h}(x) - y )^2 \bigg]  \\ 
&= \mathbb{E}_{ x,y, \mathcal{D}  }  \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x))^2 + (\bar{h}(x) - y )^2 + 2 (h_{\mathcal{D}}(x) - \bar{h}(x))  (\bar{h}(x) - y ) \bigg]
\end{align}$$

Using linearity of expectation

$$\begin{align}\mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ (h_{\mathcal{D}}(x)- y )^2 \bigg] &= \mathbb{E}_{ x,y, \mathcal{D}  }  \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x))^2 \bigg]  + \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - y )^2 \bigg]  + \mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ 2 (h_{\mathcal{D}}(x) - \bar{h}(x))  (\bar{h}(x) - y ) \bigg] \end{align} $$


For the third term $$\mathcal{D}$$ and $$(x,y)$$ are independent thus we can write 

$$ \begin{align}\mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ 2 (h_{\mathcal{D}}(x) - \bar{h}(x))  (\bar{h}(x) - y ) \bigg] &= \mathbb{E}_{ x,y } \bigg[ 2  \mathbb{E}_{\mathcal{D}} [h_{\mathcal{D}}(x) - \bar{h}(x)]  (\bar{h}(x) - y ) \bigg]\\   &= \mathbb{E}_{ x,y } \bigg[ 2  [ \bar{h}(x) - \bar{h}(x)]  (\bar{h}(x) - y ) \bigg] \\ &=   \mathbb{E}_{ x,y } \bigg[  0   \bigg]\\ &= 0
\end{align}$$ 

Thus, expected error becomes 

$$\begin{align}\mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ (h_{\mathcal{D}}(x)- y )^2 \bigg] &= \mathbb{E}_{ x,\mathcal{D}  }  \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x))^2 \bigg]  + \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - y )^2 \bigg]   \end{align} $$


Now, Let's take the second term $$\mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - y )^2 \bigg]$$ and try to decompose it further 

$$\begin{align}\mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - y )^2 \bigg] &= \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - \bar{y}(x) + \bar{y}(x) - y )^2 \bigg] \\ &=   \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - \bar{y}(x))^2 + (\bar{y}(x) - y )^2  + 2 (\bar{h}(x) - \bar{y}(x)) (\bar{y}(x) - y ) \bigg] \\ &=  \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - \bar{y}(x))^2\bigg]  + \mathbb{E}_{ x,y  } \bigg[ (\bar{y}(x) - y )^2 \bigg] +  \mathbb{E}_{ x,y  } \bigg[ 2 (\bar{h}(x) - \bar{y}) (\bar{y} - y ) \bigg] \end{align}$$


Again consider the third term, 

$$ \begin{align} \mathbb{E}_{ x,y  } \bigg[ 2 (\bar{h}(x) - \bar{y}(x)) (\bar{y} - y ) \bigg] &= \mathbb{E}_{x } \bigg[ 2  \mathbb{E}_{y \mid x } [\bar{y}(x) - y ] (\bar{h}(x) - \bar{y}(x) )  \bigg] \\ &=  \mathbb{E}_{x } \bigg[ 2  \bar{y}(x) - \mathbb{E}_{y \mid x }[y ] (\bar{h}(x) - \bar{y}(x) )  \bigg] \\ &= \mathbb{E}_{x } \bigg[ 2  \bar{y}(x) - \bar{y}(x) (\bar{h}(x) - \bar{y}(x) )  \\ &=  \mathbb{E}_{x } \bigg[ 0\bigg] \\ &= 0
\end{align}$$


Thus, 

$$\begin{align}\mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - y )^2 \bigg] &=  \mathbb{E}_{ x,y  } \bigg[  (\bar{h}(x) - \bar{y}(x))^2\bigg]  + \mathbb{E}_{ x,y  } \bigg[ (\bar{y}(x) - y )^2 \bigg] \end{align}$$
 

Thus, the expected error given an algorithm $$\mathcal{A}$$ is 

$$\begin{align}\mathbb{E}_{ x,y, \mathcal{D}  } \bigg[ (h_{\mathcal{D}}(x)- y )^2 \bigg] &= \mathbb{E}_{ x  } \bigg[  (\bar{h}(x) - \bar{y}(x))^2\bigg]  + \mathbb{E}_{ x,\mathcal{D}  }  \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x))^2 \bigg]  + \mathbb{E}_{ x,y  } \bigg[ (\bar{y}(x) - y )^2 \bigg] \\ &=  \mathrm{Bias}^2 + \mathrm{Variance} + \mathrm{Irreducible ~ Noise} 
 \end{align} $$


- **Bias:** <!--- $$ \mathbb{E}_{ x  } \bigg[  (\bar{h}(x) - \bar{y}(x))^2\bigg] $$ --> 
- **Variance:**  <!--- $$  \mathbb{E}_{ x,\mathcal{D}  }  \bigg[ (h_{\mathcal{D}}(x) - \bar{h}(x))^2 \bigg] $$ -->
- **Noise:**  <!--- $$\mathbb{E}_{ x,y  } \bigg[ (\bar{y}(x) - y )^2 \bigg] $$ -->
